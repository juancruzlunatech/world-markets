# World Markets

Web estática con **React**, **TypeScript**, **JavaScript** y **Tailwind CSS**. Muestra índices de las principales bolsas del mundo (Yahoo Finance) y noticias internacionales filtradas por país (Google News RSS).

## Desarrollo local

```bash
npm install
npm run dev
```

## Publicación

El flujo de GitHub Actions despliega `dist/` en GitHub Pages al hacer push a `main`.
